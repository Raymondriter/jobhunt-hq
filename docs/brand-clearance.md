# Brand clearance — "JobHunt HQ" (checked Nov 20, 2026, read-only)

**Verdict: RISKY for a public brand launch.** Fine for a private/personal learning project. Nothing in this memo is a legal opinion; a manual USPTO search and, before any real spend, a trademark attorney's clearance opinion are the next verification steps.

## Trademark (US)
- No live federal registration/application for the exact phrase "JOBHUNT HQ" was found in web-indexed trademark sources (Justia, TrademarkElite, Unibrander). **Gap:** the USPTO search system (tmsearch.uspto.gov) is a JavaScript app and could not be queried in this check — a manual search is still required.
- "JOB-HUNT" is a **registered US trademark**: NETability, Inc., Serial 77038271, Class 35 (advertising/business), registered. A second registration "JOB · HUNT": Bold Limited, Serial 98181863, Class 035 (business and career networking services), registered 2024-09-10. "HQ" is a generic suffix and adds little distinctiveness — an inference, not a legal conclusion.

## Collisions — exact-name uses already in job search
1. **Done For You Global — "Job Hunt HQ"** (doneforyouglobal.com/jobhunthq/): a $15 paid tracker — kanban + table tracker, resume builder, match score, interview prep, follow-up reminders. Same category, same name, overlapping positioning. Closest collision.
2. **rembrandtreyes/jobhunt-hq** (GitHub, Sep 2026): open-source "Job Hunt HQ" tracker; predates this repo.
3. **Endor Digital — "JobHuntHQ"** at jobhunthq.co.uk: tracker with AI interview prep.
4. **UCN Apps — "JobHuntHQ"**: white-label AI job-search platform (jobhunt.ucnapps.com).
5. **Job Hunt HQ — AI Job Search Command Center** (jobhuntcommand.com, $47).
6. **Job Hunt HQ – Notion Tracker** (Gumroad, $7).
Plus "JobHunt" alone is saturated (a 100K+-download mobile app, Job-Hunt.org, multiple open-source trackers).

## Practical reading
Public launch under this name invites confusion, search/Product Hunt collisions, and rebrand pressure. If the product goes public, pick a distinctive name that does not lead with "JobHunt", and screen it the same way (USPTO manual search, domains, handles, collisions) before spending on it.
