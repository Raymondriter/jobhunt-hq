# Demo applications

Import `applications-seed.csv` once from the **Import** page of a demo account.
It adds four fictional applications. The saved packet has an unanswered question,
the applied record has a sample confirmation, and two other rows show an interview
and a rejection. The fixed dates keep the example reproducible.

Each import adds rows to the signed-in account. Importing the same file twice
creates duplicates. Use a separate file outside the repository for personal records.
